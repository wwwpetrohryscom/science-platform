A scientific name is two words long, and only the first is a name in its own right. That construction is not a typographic habit inherited from Linnaeus. It is load-bearing: the second word designates nothing on its own, the first asserts membership in a group, and the pair is tied to a designated object in a collection. Those three properties together account for the behaviour that most frustrates people who use names without making them — a familiar binomial is replaced, and no new organism has been found and no old one lost.

## Two words, one of which is not a name

Zoology and botany describe the same construction in different vocabulary, and the difference reveals what each code takes the second word to be. The zoological code states that [the scientific name of a species](https://code.iczn.org/chapter-2-the-number-of-words-in-the-scientific-names-of-animals/article-5-principle-of-binominal-nomenclature/) "is a combination of two names (a binomen), the first being the generic name and the second being the specific name", with a subspecies taking a trinomen. The botanical code says that [the name of a species](https://www.iapt-taxon.org/nomen/pages/main/art_23.html) "is a binary combination consisting of the name of the genus followed by a single specific epithet". Zoology calls the second word a name; botany calls it an epithet and reserves "name" for the combination.

Both descriptions carry the same consequence. The word *leo* is not the name of a lion; it designates something only once attached to *Panthera*, and the same epithet recurs freely across unrelated genera without conflict. The generic name is the part that makes an assertion, because placing a species in a genus asserts that it belongs with the species already there.

Each system also has an arbitrary opening date, because precedence requires one. Zoological nomenclature [starts on 1 January 1758](https://code.iczn.org/zoological-nomenclature/article-3-starting-point/), the date fixed for the tenth edition of Linnaeus's *Systema Naturae*; no name published earlier enters the system, though earlier descriptions and illustrations may be used as evidence. Vascular plants [start on 1 May 1753](https://www.iapt-taxon.org/nomen/pages/main/art_13.html) with Linnaeus's *Species plantarum*, mosses in 1801 with Hedwig, and several algal groups later still. Names published before those dates are not incorrect. They are invisible.

## The type fixes the name to an object, not to a description

Every available name is attached to a name-bearing type, and the zoological code is explicit about the work this does. [Fixing the name-bearing type](https://code.iczn.org/the-type-concept-in-nomenclature/article-61-principle-of-typification/) "provides the objective standard of reference for the application of the name it bears", and "no matter how the boundaries of a taxonomic taxon may vary in the opinion of zoologists the valid name of such a taxon is determined from the name-bearing type(s) considered to belong within those boundaries". The type of a species-group name is a specimen or set of specimens — a holotype, lectotype, neotype or series of syntypes. The type of a genus-group name is not a specimen at all but a species, itself defined by its own type; the type of a family-group name is a genus. Typification is a chain, each rank anchored to the one below it.

The most common misreading is that a type is a representative individual. The botanical code disposes of that in one sentence: the nomenclatural type is [the element to which a name is permanently attached](https://www.iapt-taxon.org/nomen/pages/main/art_7.html), and it "is not necessarily the most typical or representative element of a taxon". A holotype can be a juvenile, an aberrant colour form, or the only individual anyone has collected. Its function is arbitration, not description.

That function shows up whenever a group is divided. If a species turns out to contain two lineages, the existing name stays with whichever lineage contains the type, regardless of which fragment is larger, better known or more economically important; the other lineage needs a name of its own. The same anchoring separates two kinds of synonymy that are routinely conflated. Names with different types that a specialist judges to belong to one taxon are [subjective synonyms](https://code.iczn.org/the-type-concept-in-nomenclature/article-61-principle-of-typification/), and a later specialist can undo that judgement. Names sharing a type are objective synonyms, and nothing short of Commission action can separate them. One is an opinion; the other is arithmetic.

## Priority is a rule about literature, with thresholds

Where several available names compete, [the valid name](https://code.iczn.org/validity-of-names-and-nomenclatural-acts/article-23-principle-of-priority/) is "the oldest available name applied to it, unless that name has been invalidated or another name is given precedence by any provision of the Code or by any ruling of the Commission". The code is candid that this serves an aim rather than a truth: priority "is to be used to promote stability and it is not intended to be used to upset a long-accepted name in its accustomed meaning by the introduction of a name that is its senior synonym or homonym".

When strict priority would destabilise usage, precedence can be reversed, and the test is arithmetic rather than editorial. The forgotten senior name must not have been used as a valid name after 1899, and the junior name in current use must appear as a presumed valid name in at least 25 works, published by at least 10 authors, within the immediately preceding 50 years and spanning not less than 10 years. Where both conditions hold, the senior name becomes a *nomen oblitum* and the junior a *nomen protectum*. Botany reaches a similar end by committee instead: names may be [conserved](https://www.iapt-taxon.org/nomen/pages/main/art_14.html) to avoid disadvantageous changes, with conservation aimed at "retention of those names that best serve stability of nomenclature" and the conserved names listed in appendices to the code. Both mechanisms exist because priority applied without exception would cost more stability than it buys — the tension examined in [the rules that keep names stable](/en/biology/taxonomy/taxonomy-and-classification-explained).

## Moving a species rebuilds its name

Because the genus is part of the name, a change of genus is a change of name. The botanical code makes the mechanism explicit: a taxon with a given circumscription, position and rank [can bear only one correct name](https://www.iapt-taxon.org/nomen/pages/main/art_11.html), and for any taxon below the rank of genus that correct name is "the combination of the final epithet of the earliest legitimate name of the taxon at the same rank, with the correct name of the genus or species to which it is assigned". The epithet is the durable unit and carries the priority; the binomial is reassembled each time the epithet moves. When *Antirrhinum spurium* is transferred to *Linaria* it becomes *L. spuria* — the epithet survives, its ending changed to agree with the gender of the new genus, and no proposal by the transferring author to substitute a different epithet has standing. The zoological equivalent is the case most people have met without noticing: Linnaeus described the lion in *Felis*, and the name in use is now *Panthera leo* (Linnaeus, 1758).

Recombination is not a marginal category of change. The second version of the Mammal Diversity Database, comparing itself directly against its first, recorded 296 species described de novo, 321 species split and 357 lumped, alongside 227 generic changes, 17 changes to a specific epithet and 148 spelling changes. The 227 generic transfers altered names without altering anyone's view of which populations belong together, and a reader who sees only that a binomial has changed cannot tell which category produced it.

## What the authority string is telling you

The name that follows a binomial is not part of it. Zoological authorship citation is [optional, "although customary and often advisable"](https://code.iczn.org/authorship/article-51-citation-of-names-of-authors/), and it follows the name without punctuation — except in changed combinations, where the author's name and date are enclosed in parentheses. *Taenia diminuta* Rudolphi becomes *Hymenolepis diminuta* (Rudolphi) on transfer. The parentheses are a diagnostic, not a demotion: they record that a taxonomic decision has intervened since the original description. The convention has a narrow exception, applied when the species-group name was originally published with a misspelling or emendation of the generic name.

Botany uses a related but distinguishable convention. [Author citation for a name with a basionym](https://www.iapt-taxon.org/nomen/pages/main/art_49.html) comprises the author of the basionym in parentheses followed by the author of the new combination, so *Medicago polymorpha* var. *orbicularis* L., raised to species, is cited as *M. orbicularis* (L.) Bartal. The second name is not a co-describer. It identifies whoever performed the nomenclatural act, which points at the publication where the reasoning can be checked.

## More names than organisms, by a wide margin

Synonymy is the normal condition of a worked-over group rather than an occasional untidiness. The World Checklist of Vascular Plants, in the version prepared on 16 March 2021, comprised 1,190,715 records: 400,341 accepted names, 744,145 synonyms, 3,610 artificial hybrids and 42,619 names that could not be placed. Roughly two synonyms stand behind every accepted plant species name. Mammals, the best-catalogued class of animals, run higher still — 50,230 curated species-rank synonyms against 6,759 valid species, of which 6,629 are wild and extant, 113 extinct and 17 domestic.

Those ratios are not a measure of error. They are the accumulated record of two and a half centuries of independent description, revision and transfer, and they are why a name entered into a database without its authority and date is often ambiguous. How such totals are assembled, and why two checklists of the same organisms disagree, is taken up in [how many species exist](/en/biology/taxonomy/how-many-species-are-there).

## The name is a hypothesis, and the code does not test it

The codes are deliberately silent about biology. The zoological commission states the division plainly: taxonomy and nomenclature are ["closely allied, but separate and complementary endeavours"](https://www.iczn.org/outreach/faqs/), and nomenclature "does not determine the inclusiveness or exclusiveness of any taxon, nor the rank to be accorded to any assemblage of animals, but rather provides the name that is to be used for a taxon whatever taxonomic limits and rank are given to it". The Commission itself does not patrol the literature; it rules on cases brought to it by taxonomists, acting as arbitrator.

What the binomial asserts is therefore a hypothesis in two parts. The first is that the type specimen belongs to a lineage distinct from those carrying other names — a claim whose criteria are contested, as [the species problem](/en/biology/taxonomy/what-is-a-species) sets out. The second is that this lineage belongs with the other species assigned to the genus, a claim about relationship testable by the methods described in [phylogenetic inference](/en/biology/taxonomy/phylogenetics-explained) and, at the identification end, in [DNA barcoding and its limits](/en/biology/taxonomy/dna-barcoding-and-its-limits). Neither claim is settled by any provision of any code, which decides only which string of characters the hypothesis is filed under.

The practical consequence is unglamorous and consistently ignored: record the authority and date, note whether it is parenthesised, and record which checklist version supplied the name. Without those, a binomial in a dataset is a hypothesis with its provenance stripped off, and a later reader cannot tell whether a change in it reflects new evidence about organisms or a correction to the record.
